Introduction to Python

When I first started learning Python, I didn’t really know anything about programming at all. I decided to learn it independently because I needed it for robotics, and I was intrigued by the code for our robot.

One of the first concepts I learned was variables. I learned that variables help you store information so that you can use them in your program. As an example, I used: 

name = "Bob"
age = 1000

print(name)
print(age)

This created two variables and printed their values.

Another concept I learned was if statements. They allow a program to make decisions based on whether something is true or false. I used this code: 

age = 9

if age >= 13:
    print("You are a teenager!")
else:
    print("You are not a teenager yet!")

This checks whether the age is at least 13. Since the age is 9, the program prints that the user is not a teenager yet!!

The third concept I learned was loops, which are useful if you want to repeat something. For example: 

for i in range(500):
    print("Learning Python")

This prints “Learning Python” 500 times. Instead of writing the same print() statement 500 times, I can use a loop to repeat it.

One problem I ran into was forgetting that Python uses indentation. Without the correct indentation, the code would not run. Once I figured out that the lines inside my if statements and loops needed to be indented, I was able to fix the problem.

So far, Python has shown me that coding is a lot of trial and error. You just need to get the hang of it and learn from your mistakes. Hopefully, in the future, I can learn how to build bigger projects and use Python for robotics too!

Learning About Git and GitHub

When I first started working on my website, I also started learning about Git. I learned that Git is a system that keeps track of changes made to a project. This can be really helpful if something goes wrong because I can look back at an earlier version instead of starting over.

One thing that confused me at first was the difference between Git and GitHub. They are connected, but they aren't the same thing. Git is the tool that tracks changes to my files, while GitHub is an online platform where I can store my projects. So, Git keeps track of my work, and GitHub lets me keep that work online.

I learned five main Git commands while creating my website:

  • git init — Starts a repository.
  • git status — Shows me what has changed.
  • git add — Prepares my files to be saved.
  • git commit — Saves those changes as a new version.
  • git push — Sends those changes to GitHub.

I used Git throughout the process of creating and updating my website. Whenever I made a change, I could save it and then push the updated version to GitHub. Because of this, I was not as worried about losing information.

I also ran into a problem while using Git. When I tried to push my changes, I got an error, and I wasn't sure what I had done wrong. I checked the error message and looked through my code to see what was happening. Eventually, I realized that my project and the GitHub code weren't completely synced. Once I fixed the problem, I was able to change my code again.
